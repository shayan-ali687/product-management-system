
# Product Management System

A simple Product Management System developed as a university project using PHP and MySQL.

## Features
- Insert new products
- Delete products using Product ID
- Search products by ID
- Display product details

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- XAMPP

## Database Setup
1. Start Apache and MySQL in XAMPP.
2. Create a database named `october`.
3. Follow the instructions in `database_setup.txt`.
4. Place the project folder inside `htdocs`.
5. Open the project through your local server.
